## Task
We need a calagopus plugin for managing minecraft server data.

## Features
- Support for 1.20.1 and 1.21.1, at least
- server.properties editor
- Mod Manager (Auto-update, mod version pinning, adding mods, Modrinth and CurseForge integration) (Plugin Manager is NOT needed, we only run Fabric and (Neo)Forge servers)
- Visual Whitelist Editor

We might need more features down the line, for example a world manager, but for now these are the important ones we should focus on.
